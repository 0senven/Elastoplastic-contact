# 独立版弹塑性接触 FNO

## 随机形貌的监督终态预测

`train_terminal.py` 从 `data/random surface/run_001.zip` 读取初始等效形貌和终态压力、弹性位移、塑性位移。网络输入为初始形貌、载荷、等效接触模量、材料 1 的 `n1/Q1/T1` 及 72 维傅里叶坐标编码。等效接触模量按 `1 / ((1-n1²)/E1 + (1-n2²)/E2)` 计算，并与每组存档的 MATLAB 等效值核对。

一次前向输出压力和塑性位移，并通过镜像 Green-FFT 硬约束 `u_e = G(p)/E*` 计算弹性位移。压力非负且按单元面积积分约束总法向载荷。三场使用按训练集 RMS 归一化的 MSE，压力另加参考承压区 MSE。弹性数据损失通过 Green 算子回传到压力分支。默认按整组工况以固定种子划分 24 组训练、3 组验证和 3 组测试，按验证损失保存最佳权重。

```powershell
python train_terminal.py
python train_terminal.py --checkpoint runs/terminal/operator.pt --input case.npz --output runs/terminal/prediction.npz
```

预测输入 NPZ 包含与权重网格一致的 `h_equivalent`（mm）和标量 `F/E1/E2/n1/n2/Q1/T1`，其中材料 1 为软材料。输出 NPZ 的 `pressure` 单位为 MPa，`elastic` 和 `plastic` 单位为 mm。

## 迭代弹塑性模型

在 PyCharm 中打开本目录，选用安装了 `requirements.txt` 中依赖的 Python 解释器。先运行 `train_elastic.py` 训练弹性 MLP，再运行 `train.py` 训练塑性 FNO + U-Net。

在 PyCharm 终端运行 `python -m pip install -r requirements.txt` 安装依赖。配置好 CUDA 版 PyTorch 后，程序自动选择 CUDA 运行网络和 Green 位移算子。塑性训练的双线性本构使用 NumPy/SciPy。

| 文件 | 用途 |
|---|---|
| `train_elastic.py` | 第一阶段，使用接触方程训练弹性 MLP |
| `train.py` | 运行设置、二维傅里叶层与 FNO、逐步 U-Net、损失函数、三阶段优化和验收入口 |
| `physics.py` | 数据读入、矩形位移核与应力核、单步双线性本构更新 |
| `plot_validation.py` | 加载最后保存的模型，绘制五组验收场和 MATLAB 参考解 |
| `check_batch.py` | 对比 Adam 的 batch=1 和 batch=4，并检查抽样与工况状态推进 |
| `data/` | 运行时读取的 `cases.csv`、原始 Excel、三个形貌与网格 MAT 文件、只在验收阶段读取的参考 ZIP |
| `results_128/` | 旧版轨迹监督模型的权重和报告，供历史对照 |
| `runs/` | 新运行的输出目录，由脚本自动建立 |

## 运行方式

先运行弹性训练。坐标归一化到 `[-1, 1]`，再生成 72 维傅里叶编码。MLP 读取当前形貌和傅里叶坐标，预测全局辅助场，每个网格点另有一个可训练的局部修正值。当前等效间隙、辅助场和局部修正一起构造压力候选场，再做单纯形投影，得到非负且满足总法向载荷的压力。Green-FFT 从压力恢复弹性位移。弹性训练使用前 25 组工况。每个工况使用原始形貌和两种削平凸峰得到的合成等效形貌，三种形貌都只用接触物理残差训练，无需参考场标签。

弹性训练三个阶段均使用辅助场全局残差、FB 残差均方和归一化最大穿透量平方。前两阶段还加入承压区残差、最大 128 点残差和最大 32 点穿透惩罚。第一阶段为 Adam 3000 步、L-BFGS 150 步。第二阶段为 Adam 1000 步、L-BFGS 200 步，并对承压区采用平滑权重。第三阶段冻结坐标 MLP 和坐标偏移，用全局残差、FB 残差和最大穿透惩罚对局部场进行双精度 L-BFGS 200 步精修。

```powershell
python train_elastic.py
```

弹性权重默认保存到 `runs/elastic/elastic.pt`。完成后再单独启动塑性训练。塑性训练和绘图都可用 `--elastic-checkpoint` 指定弹性权重，使用期间弹性网络冻结。

训练期间按固定间隔和各阶段末尾检查候选权重。检查使用第 5、10、15、20、25 组工况的初始形貌，以及额外的削峰形貌。仅当所有检查样本的最大无量纲 FB 残差 ≤ `2e-4`、最大穿透 ≤ `2e-6 mm`、相对载荷误差 ≤ `1e-8` 时才保存。达标候选优先比较最差样本的 FB 残差，残差相同时依次比较穿透和载荷误差。选模无需 MATLAB 标签。如果整次训练没有达标候选，程序报告失败并保留已有权重文件。

弹性 MLP 的每个网格点有两个可训练的坐标偏移，和网络权重一起由 Adam 和 L-BFGS 更新。偏移从零开始，各方向最多移动半个网格间距，仅用于生成 72 维傅里叶编码。Green 算子和载荷积分使用原物理网格。权重保存坐标偏移，换网格尺寸时在新网格上插值。局部修正也随权重保存并支持换网格插值。此前架构的弹性权重需要重新训练。

```text
python train.py
python train.py --size 128 --smoke --physics-workers 1
python train.py --size 128 --pilot
python train.py --size 512 --smoke --physics-workers 1
python train.py --checkpoint runs/本次运行目录/operator.pt
```

在 PyCharm 直接运行 `plot_validation.py`，会按保存时间选取最新的 `operator.pt`，用该模型执行第 26–30 组验收并保存对照图。每组一张 PNG，包含压力、弹性位移和塑性位移三行，每行依次是预测、MATLAB 参考和带符号的差值。预测和参考共用色标，MATLAB 参考经面积平均对齐到模型网格。图片默认保存在模型目录的 `plots/`。

```text
python plot_validation.py
python plot_validation.py --checkpoint runs/本次运行目录/operator.pt
python plot_validation.py --saved
python plot_validation.py --case 26 --load 920
```

`--case` 从 `cases.csv` 选取一个工况，`--load` 可覆盖法向载荷（N）。该模式仅预测所选工况，直接输出最终压力、弹性位移、塑性位移和间隙的 NPZ 文件，以及记录输入、实际预测轮数和收敛状态的 JSON 文件。默认输出到权重目录的 `plots/`，可用 `--output` 指定目录。

`--saved` 直接用对应运行目录中已有的验收结果绘图，适用于验收已经完成的模型。默认模式重新推理，耗时取决于塑性迭代步数。

在 PyCharm 运行 `check_batch.py` 可做批量大小对照。默认用 64×64 网格，每组训练工况访问 8 次。两组对照使用相同初始权重、工况访问顺序和工况访问总数，实际 Adam 更新次数随 batch 大小而不同。输出的 `summary.json` 记录抽样和状态检查、各固定状态的本构残差，以及网络增量已达停止阈值时本构增量仍超阈值的重置次数。测试使用前 25 组的在线本构，结果保存在 `batch_checks/`。

图中 MATLAB 耗时取自参考包各工况 `parameters.mat` 的 `compute_time_s`。模型求解耗时 `model_solve_s` 包括工况初始化、弹性推理、塑性网络预测和位移更新。权重和参考场加载、核构建、与参考场的误差计算、文件保存及绘图均在计时之外。用 `--saved` 读取旧报告时，若只有 `elapsed_s`，图上标为 Model validation，该耗时也包含此前轮次的验收统计及保存开销。

直接运行时，网格尺寸取 `train.py` 顶部的 `SIZE`，也可以用 `--size` 指定。完整训练使用工况 1–25。网络宽度 12、每方向 8 个频域模态、3 层傅里叶块、每次 Adam 更新使用 1 个工况。第一阶段只用 Adam 3000，第二阶段 Adam 1000 / L-BFGS 200，第三阶段 L-BFGS 200。Adam 计参数更新次数，L-BFGS 计外层调用次数，每次调用可以执行多次线搜索评估。`--pilot` 仍使用 1–25，三个阶段缩短为 300/0、100/20、0/20。`--smoke` 用前两组作流程检查，跑 5 个优化步骤，验收最多推进 3 个塑性步。所有方式只在最终验收读取工况 26–30 的 ZIP。`--checkpoint` 读取新版在线本构残差模型，并恢复网格和深度设置。旧版模型输出的是终态位移，需用对应的旧版程序读取。

`data/cases.csv` 由原始 Excel 首个工作表的 30 组工况逐行导出。训练直接读 CSV，以避开不同 Python 环境中的 Excel 依赖。修改工况请同步更新 CSV，并保留 `CaseID` 的 1–30 顺序。验收工况的参数需与参考 ZIP 对应。

Adam 在每个有 Adam 更新的阶段从配置学习率开始，通过训练损失的移动平均调节学习率。L-BFGS 使用 strong-Wolfe 线搜索，每 5 步重新选定工况块并重建准牛顿历史。线搜索期间固定各步的形貌、接触解、本构右端和权重。第一阶段优化全场本构残差，第二阶段加入承压点中压力最高 5% 的局部残差，第三阶段降低局部项的先验权重。两项权重按训练残差的移动平均调整。

训练从各工况保存的塑性状态出发。每次 Adam 更新或每个 L-BFGS 工况块结束后，用更新后的网络提交一次塑性位移更新，硬化历史由本构更新以生成后续监督目标。下次抽到该工况时，在保存的状态上重新求压力和本构增量。工况达到塑性收敛或最大塑性步数后，下次从初始状态开始。

一次抽取指选中完整的工况和它对应的全场网格。Adam 每轮把 25 组训练工况打乱，再按顺序取样。默认 `--batch 1`，一次 Adam 更新用一组，所有组用完后再次打乱。L-BFGS 也按打乱后的工况顺序逐块取样，取完整轮后再重排。默认每个块取一组，块内共用该工况。第二、三阶段各有 40 个工况块，前 25 块覆盖全部 25 组。

## 物理模型和训练

1. 固定表面是 512×512。把相邻 4×4 单元面积平均到 128×128，域宽维持 1.024 mm。MATLAB 的输入场是初始间隙偏置 `h1-h2-min(h1-h2)`，塑性压平使它增大，所以 Python 中采用 `h+up`。
2. 投影前的无量纲压力候选为 `(-shape/length - offset) / k`，其中 `shape` 是本项目采用的间隙形貌，`offset` 由坐标 MLP 和局部场相加得到。无量纲 `k` 由 镜像 Green 算子的均布压力响应、等效模量、名义压力和形貌归一化尺度计算。单纯形投影先令无量纲压力均值为 1，再乘以名义压力。FB 和最大穿透用于训练与选模，载荷误差用于选模和报告。
3. 软材料采用参考脚本的双线性等效应力更新。应力核用软侧泊松比，屈服和切线模量取材料 1，深度积分中的应变分母依照 MATLAB 的定义取等效接触模量。物理轨迹沿用 MATLAB 每轮更新局部硬化阈值、再累加 0.1 倍塑性增量的做法。初试把原始 51 层分组到 14 个深度积分点，保持原始深度范围。`--depth-stride 1` 可恢复 51 层。
4. 每个工况从零塑性位移和初始屈服强度出发。双线性本构用当前压力和逐深度硬化状态生成表面位移增量及各深度屈服阈值增量的监督目标。两项残差各按工况内的目标最大值归一化，尺度下限分别为 5e-6 mm 和 0.1 MPa，再将各自的全场及高压区均方残差相加。训练位移用网络预测推进，生成监督目标所需的硬化历史由本构独立推进。
5. FNO 输入当前等效形貌、接触压力、四个工况参数和 72 个傅里叶坐标通道。FNO 与 U-Net 共同预测各深度非负屈服超量。输出层按双线性公式用同一超量计算表面塑性位移增量和逐深度硬化增量，使用 Softplus 保证非负，并保留负预测值处的训练梯度。硬化增量作为辅助监督输出，旧 ReLU 版权重需要重新训练。

## 验收和输出

`operator.pt` 保存模型，`stage_*.pt` 保存阶段权重，`training.jsonl` 记录逐步损失、训练工况编号、采样类型和当前塑性步（从 0 起算）。

`training_probe.jsonl` 记录固定训练工况的原始全场本构残差 MSE，单位为 mm²。完整训练使用第 25 组，比较第 1、2、3 和 33 步，最后一个状态已经完成 32 次纯本构更新。短测用第 2 组，最晚记录第 4 步。监测状态在训练开始前计算一次，训练中只读。初始、每 250 次 Adam 更新、每 50 次 L-BFGS 更新及两种优化器各阶段末尾都会写入一条。监测值用于对比训练进度。

`validation.json` 记录第 26–30 组的最终三场误差、收敛状态、轮数、载荷和接触指标，每完成一组即写入。验收检查参考包的工况参数和原始形貌，并对 512×512 参考场做面积平均以对齐模型网格。最终预测和 MATLAB 参考场保存在 `case_XX_round_*.npz`。

每轮由弹性 MLP 根据当前形貌预测压力，塑性网络用该压力预测全场塑性位移增量。结束时复用最终形貌的压力，通过 Green 算子计算一次弹性位移。硬化增量参与训练监督，验收只累加塑性位移并用新形貌求接触。预测增量的全场最大值小于 `PLASTIC_TOL_MM = 1e-6 mm` 时停止，否则累加塑性位移增量并重新调用弹性网络。常规验收最多预测 10000 轮，训练入口可用 `--max-validation-steps` 调整，绘图入口可用 `--max-plastic-steps` 调整。达到上限时仍比较最终场，并标记塑性未收敛。首轮增量低于阈值时报告未推进塑性位移，通过验收仍须满足三场误差门槛。

与参考解的误差另行统计。MSE 为全场逐点误差平方的平均值。`pressure_mse` 单位为 MPa²，`elastic_mse` 和 `plastic_mse` 的单位为 mm²。压力和塑性位移各自按原始 MSE 验收，门槛字段为 `pressure_mse_limit` 和 `plastic_mse_limit`。每组门槛是该组对应参考场均方值的 0.0025 倍，等价于此前 5% 的相对 L2 尺度。每组通过验收需要塑性收敛、两项 MSE 均达到各自门槛，以及弹性位移相对 L2 ≤5%。

报告同时记录压力和塑性位移的 MAE，即全场逐点绝对误差的平均值。`pressure_mae` 的单位为 MPa，`plastic_mae` 的单位为 mm。MAE 用于报告误差大小，通过门槛按 MSE 判定。

参考由原始 512×512 网格生成。128 运行时对参考场做面积平均后再比较，误差仍包含表面网格与深度积分差异。30 组共享同一对固定形貌。前 25 组载荷为 501–903 N，后 5 组为 911–993 N，验收包含载荷外推。

在线残差训练每个塑性步都求解接触并更新硬化状态。验收每轮预测压力和塑性位移增量，结束后计算弹性位移，耗时取决于收敛轮数。建议先在 128 网格短跑。512 首次试跑可加 `--physics-workers 1` 减少并发物理计算的内存峰值。当前网络预测单个本构小步，推理速度按实际收敛步数评估。
