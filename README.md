# 独立版弹塑性接触 FNO

在 PyCharm 中打开本目录，选用安装了 `requirements.txt` 中依赖的 Python 解释器，直接运行 `train.py`。把整个文件夹移到其他位置时，目录内部结构照原样保留即可。所有路径以 `train.py` 所在目录为基准。

在 PyCharm 终端运行 `python -m pip install -r requirements.txt` 安装依赖。配置好可用的 CUDA 版 PyTorch 后，程序自动选择 CUDA 运行网络，弹性接触和双线性本构计算使用 NumPy/SciPy。

| 文件 | 用途 |
|---|---|
| `train.py` | 运行设置、二维傅里叶层与 FNO、逐步 U-Net、损失函数、三阶段优化和验收入口 |
| `physics.py` | 数据读入、矩形位移核与应力核、镜像 Green-FFT、力控接触、单步双线性本构更新 |
| `plot_validation.py` | 加载最后保存的模型，绘制五组验收场和 MATLAB 参考解 |
| `check_batch.py` | 对比 Adam 的 batch=1 和 batch=4，并检查抽样与工况状态推进 |
| `data/` | 运行时读取的 `cases.csv`、原始 Excel、三个形貌与网格 MAT 文件、只在验收阶段读取的参考 ZIP |
| `results_128/` | 旧版轨迹监督模型的权重和报告，供历史对照 |
| `runs/` | 新运行的输出目录，由脚本自动建立 |

## 运行方式

```text
python train.py
python train.py --size 128 --smoke --physics-workers 1
python train.py --size 128 --pilot
python train.py --size 512 --smoke --physics-workers 1
python train.py --checkpoint runs/本次运行目录/operator.pt
```

在 PyCharm 直接运行 `plot_validation.py`，会按保存时间选取最新的 `operator.pt`，用该模型执行第 26–30 组验收并保存对照图。每组一张 PNG，包含压力、弹性位移和塑性位移三行，每行依次是预测、MATLAB 参考和带符号的差值。预测和参考共用色标，MATLAB 参考经面积平均对齐到模型网格。图片默认保存在模型目录的 `plots/`。

```text
python plot_validation.py
python plot_validation.py --checkpoint runs/本次运行目录/operator.pt
python plot_validation.py --saved
```

`--saved` 直接用对应运行目录中已有的验收结果绘图，适用于验收已经完成的模型。默认模式重新推理，耗时取决于塑性迭代步数。

在 PyCharm 运行 `check_batch.py` 可做批量大小对照。默认用 64×64 网格，每组训练工况访问 8 次。两组对照使用相同初始权重、工况访问顺序和工况访问总数，实际 Adam 更新次数随 batch 大小而不同。输出的 `summary.json` 记录抽样和状态检查、各固定状态的本构残差，以及网络增量已达停止阈值时本构增量仍超阈值的重置次数。测试使用前 25 组的在线本构，结果保存在 `batch_checks/`。

图中 MATLAB 耗时取自参考包各工况 `parameters.mat` 的 `compute_time_s`。模型求解耗时 `model_solve_s` 包括工况初始化、接触求解、在线本构检查、FNO 预测和塑性更新。权重和参考场加载、核构建、与参考场的误差计算、文件保存及绘图均在计时之外。用 `--saved` 读取旧报告时，若只有 `elapsed_s`，图上标为 Model validation，该耗时也包含此前轮次的验收统计及保存开销。

直接运行时，网格尺寸取 `train.py` 顶部的 `SIZE`，也可以用 `--size` 指定。完整训练使用工况 1–25。网络宽度 12、每方向 8 个频域模态、3 层傅里叶块、每次 Adam 更新使用 1 个工况。第一阶段只用 Adam 3000，第二阶段 Adam 1000 / L-BFGS 200，第三阶段 L-BFGS 200。Adam 计参数更新次数，L-BFGS 计外层调用次数，每次调用可以执行多次线搜索评估。`--pilot` 仍使用 1–25，三个阶段缩短为 300/0、100/20、0/20。`--smoke` 用前两组作流程检查，跑 5 个优化步骤，验收最多推进 3 个塑性步。所有方式只在最终验收读取工况 26–30 的 ZIP。`--checkpoint` 读取新版在线本构残差模型，并恢复网格和深度设置。旧版模型输出的是终态位移，需用对应的旧版程序读取。

`data/cases.csv` 由原始 Excel 首个工作表的 30 组工况逐行导出。训练直接读 CSV，以避开不同 Python 环境中的 Excel 依赖。修改工况请同步更新 CSV，并保留 `CaseID` 的 1–30 顺序。验收工况的参数需与参考 ZIP 对应。

Adam 在每个有 Adam 更新的阶段从配置学习率开始，通过训练损失的移动平均调节学习率。L-BFGS 使用 strong-Wolfe 线搜索，每 5 步重新选定工况块并重建准牛顿历史。线搜索期间固定各步的形貌、接触解、本构右端和权重。第一阶段优化全场本构残差，第二阶段加入承压点中压力最高 5% 的局部残差，第三阶段降低局部项的先验权重。两项权重按训练残差的移动平均调整。

训练从各工况保存的塑性状态出发。每次 Adam 更新或每个 L-BFGS 工况块结束后，用更新后的网络提交一次塑性位移和硬化更新。下次抽到该工况时，在保存的状态上重新求压力和本构增量。工况达到塑性收敛或最大塑性步数后，下次从初始状态开始。

一次抽取指选中完整的工况和它对应的全场网格。Adam 每轮把 25 组训练工况打乱，再按顺序取样。默认 `--batch 1`，一次 Adam 更新用一组，所有组用完后再次打乱。L-BFGS 也按打乱后的工况顺序逐块取样，取完整轮后再重排。默认每个块取一组，块内共用该工况。第二、三阶段各有 40 个工况块，前 25 块覆盖全部 25 组。

## 物理模型和训练

1. 固定表面是 512×512。把相邻 4×4 单元面积平均到 128×128，域宽维持 1.024 mm。MATLAB 的输入场是初始间隙偏置 `h1-h2-min(h1-h2)`，塑性压平使它增大，所以 Python 中采用 `h+up`。
2. 对给定等效间隙，矩形 Green 核按两侧接触模量计算，使用 MATLAB 参考的镜像延拓。压力投影硬满足总力和非负性。接触验收要求最大无量纲 FB 残差不超过 2e-4、最大穿透不超过 2e-6 mm，以及载荷相对误差不超过 1e-8。载荷相对误差取压力积分与给定载荷之差的绝对值除以给定载荷。
3. 软材料采用参考脚本的双线性等效应力更新。应力核用软侧泊松比，屈服和切线模量取材料 1，深度积分中的应变分母依照 MATLAB 的定义取等效接触模量。物理轨迹沿用 MATLAB 每轮更新局部硬化阈值、再累加 0.1 倍塑性增量的做法。初试把原始 51 层分组到 14 个深度积分点，保持原始深度范围。`--depth-stride 1` 可恢复 51 层。
4. 每个工况从零塑性位移和软材料初始屈服强度出发。每步在网络已预测的有效形貌上求压力，再按当前压力和逐深度硬化状态计算本构增量。损失是 `网络预测增量 − 当前状态的本构增量` 的全场和高压区均方。归一化尺度取当步本构增量最大值与 `5e-6 mm` 中较大者。发生屈服的网格柱使用网络预测增量推进表面塑性位移。各深度的硬化状态直接采用双线性本构根据当前压力和上一轮硬化状态计算出的结果。网络预测与本构增量之间的误差用于计算训练损失。下一轮在更新后的形貌上重新求压力。
5. FNO 输入当前等效形貌 `h+up`、压力场、四个工况参数（接触等效模量、软材料泊松比、初始屈服强度、切线模量）、逐深度硬化状态和 72 个固定随机傅里叶坐标通道。U-Net 在每个塑性步读取当前等效形貌和压力场，输出与 FNO 相加后由 Softplus 得到非负塑性位移增量。默认 14 个硬化深度时，FNO 共读入 92 个通道。形貌除以初始形貌峰谷差，压力除以 1000 MPa。弹性位移由接触求解器计算并用于验收输出。每轮损失只通过当前轮的网络预测反传，物理求解和已推进的历史状态作为固定输入。验收和绘图按权重保存的输入格式和 U-Net 配置加载，已有权重沿用训练时的物理场和工况通道格式。

## 验收和输出

`operator.pt` 保存模型，`stage_*.pt` 保存阶段权重，`training.jsonl` 记录逐步损失、训练工况编号、采样类型和当前塑性步（从 0 起算）。

`training_probe.jsonl` 记录固定训练工况的原始全场本构残差 MSE，单位为 mm²。完整训练使用第 25 组，比较第 1、2、3 和 33 步，最后一个状态已经完成 32 次纯本构更新。短测用第 2 组，最晚记录第 4 步。监测状态在训练开始前计算一次，训练中只读。初始、每 250 次 Adam 更新、每 50 次 L-BFGS 更新及两种优化器各阶段末尾都会写入一条。监测值用于对比训练进度。

`validation.json` 记录 26–30 组各步的三场 MSE、弹性位移相对 L2、峰值绝对误差、本构残差、载荷和接触验收值，每完成一组即写入。验收时程序检查参考包里的工况参数和原始形貌，再对 512×512 参考场做同一面积平均。初始和末步的预测与参考数组保存在 `case_XX_round_*.npz`。

塑性迭代按实际更新增量的全场最大值停止，门槛为 `PLASTIC_TOL_MM = 1e-6`。实际更新增量取屈服网格点的网络预测，未屈服点取零。`plastic_update_max_mm` 记录该最大值，`plastic_update_limit_mm` 记录门槛，`plastic_converged` 记录判定。达到 `--max-plastic-steps` 上限时仍按这个最大值标记。本构增量、原始网络预测及两者残差的 MSE 和峰值仍随报告记录，用于诊断。

与参考解的误差另行统计。MSE 为全场逐点误差平方的平均值。`pressure_mse` 单位为 MPa²，`elastic_mse` 和 `plastic_mse` 的单位为 mm²。压力和塑性位移各自按原始 MSE 验收，门槛字段为 `pressure_mse_limit` 和 `plastic_mse_limit`。每组门槛是该组对应参考场均方值的 0.0025 倍，等价于此前 5% 的相对 L2 尺度。每组通过验收需要塑性收敛、两项 MSE 均达到各自门槛，以及弹性位移相对 L2 ≤5%。

报告同时记录压力和塑性位移的 MAE，即全场逐点绝对误差的平均值。`pressure_mae` 的单位为 MPa，`plastic_mae` 的单位为 mm。MAE 用于报告误差大小，通过门槛按 MSE 判定。

参考由原始 512×512 网格生成。128 运行时对参考场做面积平均后再比较，误差仍包含表面网格与深度积分差异。30 组共享同一对固定形貌。前 25 组载荷为 501–903 N，后 5 组为 911–993 N，验收包含载荷外推。

在线残差版每个塑性步都要求接触并更新硬化状态，训练和推理都可能需要较长时间。建议先在 128 网格短跑。512 首次试跑可加 `--physics-workers 1` 减少并发物理计算的内存峰值。当前网络预测单个本构小步，推理速度按实际收敛步数评估。
